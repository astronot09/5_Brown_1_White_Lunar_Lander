# Lunar Skyline web application

This folder contains the React + TypeScript + Vite frontend. The repository-level [README](../../README.md) explains prerequisites, installation, development, build, preview and test commands.

To work directly in this folder:

```bash
npm ci
npm run dev
```

The application currently uses static site profiles from `public/data/sites/`; it does not require a backend service or environment variables.
